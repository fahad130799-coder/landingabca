# Elevated Living

Create a premium, modern real-estate landing page inspired by the uploaded reference screenshot.

IMPORTANT: Use the uploaded screenshot as the primary VISUAL REFERENCE for the overall design language, spacing, typography hierarchy, section composition, image treatment and minimal editorial aesthetic. Do NOT create a generic real-estate website. The final website should feel visually very close to the reference in terms of structure and premium design quality, while using original real-estate content, imagery and branding.

## DESIGN STYLE

Create a luxury architectural / modern real-estate aesthetic with:

* Minimal Scandinavian editorial design
* Premium architecture magazine feel
* Large typography
* Extremely clean white/off-white backgrounds
* Thin borders and subtle dividers
* Spacious layouts
* Asymmetric image grids
* Minimal rounded corners
* Very subtle shadows
* Black typography
* Muted grey secondary text
* High-quality architectural property photography
* Elegant, understated animations
* No gradients
* No excessive cards
* No colorful UI
* No generic real-estate template look

The website should look expensive, sophisticated, architectural and highly curated.

## COLOR PALETTE

Follow the reference screenshot closely:

* Primary background: #F7F7F5 / warm off-white
* Secondary background: #FFFFFF
* Primary text: #0A0A0A
* Secondary text: #6F6F6F
* Borders/dividers: #DCDCDC
* Hero overlay: subtle dark transparent overlay
* Buttons: #080808 with white text
* Light button: #FFFFFF with black text

Keep the color palette monochromatic and neutral.

## TYPOGRAPHY

Use a clean premium sans-serif similar to the reference.

Preferred font:

* Inter

Use:

* Headings: Inter, font-weight 300–400
* Body: Inter, font-weight 400
* Navigation: Inter, 400
* Large hero typography: Inter, 300

Typography should be elegant and lightweight rather than bold.

Hero heading should be very large on desktop, approximately 72–100px, with tight line-height around 0.9–1.0.

Section headings should be approximately 52–72px.

On mobile, scale typography intelligently while maintaining the same visual hierarchy.

## IMAGE DIRECTION

Use only premium architectural real-estate imagery.

Images should feature:

* Modern villas
* Luxury homes
* Contemporary architecture
* Glass facades
* Natural landscapes
* Trees
* Warm daylight
* Architectural photography
* Minimal interiors/exteriors

Avoid:

* Generic real-estate agent photos
* People shaking hands
* Stock-business images
* Cheap-looking property photos
* Overly saturated images

All property images should have a consistent photographic style.

## LAYOUT & SPACING

Follow the uploaded reference closely.

Use:

* Maximum content width around 1400px
* Large horizontal margins
* Generous vertical whitespace
* Thin 1px separators
* Editorial asymmetry
* Clean 12-column desktop grid
* Consistent left/right alignment
* Large image blocks

The page should NOT feel crowded.

## ANIMATIONS

Add subtle premium interactions:

* Smooth fade-up animations when sections enter viewport
* Gentle image scale on hover
* Smooth navigation scrolling
* Slight image reveal animations
* Button hover transitions
* Property image hover effect
* Smooth testimonial slider

Animations must be subtle and sophisticated.

Do NOT use:

* Bouncy animations
* Excessive parallax
* Flashy effects
* Neon effects
* Large shadows
* Overly rounded cards

## RESPONSIVE DESIGN

Desktop:
Match the reference composition closely.

Tablet:
Reorganize asymmetric grids while preserving the editorial look.

Mobile:

* Full-width hero
* Large but responsive typography
* Stacked property sections
* Horizontal scrolling property gallery where appropriate
* Clean mobile navigation
* Proper spacing
* No horizontal overflow
* Touch-friendly buttons
* Images should remain large and immersive

The mobile version should feel intentionally designed, not simply a desktop layout stacked vertically.

## UI DETAILS

Use:

* 4–8px subtle border radius where necessary
* Thin borders
* Small uppercase labels
* Tiny metadata text
* Black and white buttons
* Minimal icons
* Lots of whitespace

Buttons should be compact and elegant, not large SaaS-style buttons.
